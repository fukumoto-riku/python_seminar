# 回帰モデルと重要用語の学習メモ

## 目的

最小二乗法による回帰、Lasso回帰、PLS回帰について、モデルの原理と特徴を結びつけて説明できるようにするためのメモ。

あわせて、オートスケーリング、過学習、次元圧縮、回帰、線形、ハイパーパラメータについて整理する。

## 1. 回帰とは

回帰とは、入力データから連続値を予測するための方法。

例えば、住宅データから住宅価格を予測する、材料の組成や測定スペクトルから物性値を予測する、といった問題が回帰にあたる。

分類が「AかBか」のようなカテゴリを予測するのに対して、回帰は「価格」「温度」「濃度」「強度」のような数値を予測する。

回帰モデルでは、一般に次のような関係を考える。

```text
y = f(X) + 誤差
```

- `X`: 説明変数、特徴量、入力データ
- `y`: 目的変数、教師データ、予測したい値
- `f(X)`: モデルが学習する関係式

## 2. 線形とは

線形とは、モデルが係数に対して足し算と掛け算の形で表されること。

線形回帰の基本形は次のようになる。

```text
y = w1 x1 + w2 x2 + ... + wp xp + b
```

- `x1, x2, ..., xp`: 特徴量
- `w1, w2, ..., wp`: 各特徴量にかかる係数
- `b`: 切片

ここで重要なのは、「特徴量と係数の重み付き和」で予測するという点。

線形モデルの特徴は、各特徴量が予測値にどれくらい効いているかを係数から解釈しやすいこと。ただし、複雑な非線形関係をそのまま表すのは苦手。

## 3. 最小二乗法による回帰

### 原理

最小二乗法は、実測値と予測値のズレをできるだけ小さくするように係数を決める方法。

各データ点について、

```text
残差 = 実測値 - 予測値
```

を計算し、その残差を2乗して合計する。

```text
残差平方和 = Σ(実測値 - 予測値)^2
```

最小二乗法では、この残差平方和が最小になるような係数を求める。

### なぜ2乗するのか

残差をそのまま足すと、正の誤差と負の誤差が打ち消し合ってしまう。2乗することで、ズレの大きさをすべて正の値として扱える。

また、大きな誤差ほど2乗によって強く penalize される。そのため、外れ値の影響を受けやすい。

### 特徴

- 原理が単純で理解しやすい。
- 線形モデルなので、係数の意味を解釈しやすい。
- 特徴量の数が少なく、特徴量同士の相関が強すぎない場合に扱いやすい。
- 外れ値に弱い。
- 特徴量同士が強く相関していると、係数が不安定になりやすい。
- 特徴量の数が多い場合、過学習しやすいことがある。

### 説明例

最小二乗法は、実測値と予測値の差である残差の2乗和が最小になるように、線形回帰の係数を決める方法。シンプルで解釈しやすいが、大きな誤差を強く評価するため外れ値の影響を受けやすい。

## 4. Lasso回帰

### 原理

Lasso回帰は、最小二乗法の誤差に加えて、係数の絶対値の合計に対するペナルティを加える回帰モデル。

目的関数はイメージとして次のようになる。

```text
残差平方和 + α × 係数の絶対値の合計
```

この「係数の絶対値の合計」を L1 正則化という。

`α` は正則化の強さを決める値で、Lasso回帰における重要なハイパーパラメータ。

### 何が起こるか

Lasso回帰では、重要でない特徴量の係数が 0 になりやすい。

係数が 0 になるということは、その特徴量を予測に使わないという意味になる。そのため、Lasso回帰は回帰をしながら特徴量選択も行える。

### α の意味

- `α` が小さい: 通常の最小二乗法に近くなる。多くの特徴量を使いやすい。
- `α` が大きい: 係数を 0 にしやすくなる。モデルは単純になるが、重要な情報まで捨てる可能性がある。

### 特徴

- L1正則化により、係数の一部が 0 になりやすい。
- 特徴量選択ができる。
- 特徴量が多いときに有効。
- 過学習を抑える効果がある。
- 強く相関した特徴量が複数ある場合、そのうち一部だけを残すことがある。
- `α` の選び方が重要。

### 説明例

Lasso回帰は、最小二乗法の誤差に係数の絶対値に対するペナルティを加えた線形回帰。L1正則化によって不要な特徴量の係数が 0 になりやすいため、予測と特徴量選択を同時に行える。

## 5. PLS回帰

### 原理

PLS回帰は、元の特徴量をそのまま使うのではなく、特徴量を少数の成分に変換してから回帰する方法。

PLS は Partial Least Squares の略で、日本語では部分最小二乗法と呼ばれる。

PLS回帰では、説明変数 `X` と目的変数 `y` の関係をよく表すような新しい成分を作る。ここが PCA と異なる重要な点。

PCA は主に `X` の分散が大きい方向を探す。一方、PLS は `X` だけでなく `y` との関係も考えて、予測に役立つ方向を探す。

### なぜ使うのか

特徴量が多い場合や、特徴量同士が強く相関している場合、通常の最小二乗法では係数が不安定になりやすい。

PLS回帰では、多数の特徴量を少数の成分に圧縮してから回帰するため、多重共線性に強く、スペクトルデータや材料データのような高次元データでよく使われる。

### n_components の意味

PLS回帰では、いくつの成分に圧縮するかを `n_components` で指定する。

- `n_components` が少なすぎる: 情報が不足して予測性能が低くなる。
- `n_components` が多すぎる: ノイズまで取り込んで過学習しやすくなる。

`n_components` は PLS回帰における重要なハイパーパラメータ。

### 特徴

- 高次元データに強い。
- 特徴量同士の相関が強い場合でも使いやすい。
- 次元圧縮と回帰を同時に行う。
- 目的変数との関係を考慮した成分を作る。
- 成分数 `n_components` の選び方が重要。
- 元の特徴量ごとの単純な係数解釈は、通常の線形回帰より少し難しくなる。

### 説明例

PLS回帰は、説明変数を目的変数と関係の強い少数の成分に圧縮し、その成分を使って回帰する方法。高次元で相関の強い特徴量を含むデータに向いており、成分数の選択が重要になる。

## 6. 3つの回帰モデルの比較

| モデル | 原理 | 主な特徴 | 向いている状況 | 注意点 |
|---|---|---|---|---|
| 最小二乗法 | 残差平方和を最小化する | シンプルで解釈しやすい | 特徴量が少なく、相関が強すぎないデータ | 外れ値や多重共線性に弱い |
| Lasso回帰 | 残差平方和にL1正則化を加える | 係数が0になりやすく、特徴量選択できる | 特徴量が多いデータ | αの選び方が重要 |
| PLS回帰 | Xとyの関係を反映した成分に圧縮して回帰 | 次元圧縮と回帰を同時に行う | 高次元データ、特徴量間の相関が強いデータ | 成分数の選び方が重要 |

## 7. 用語集

### オートスケーリング

オートスケーリングとは、各特徴量を平均 0、標準偏差 1 になるように変換する前処理。

式で書くと次のようになる。

```text
z = (x - 平均) / 標準偏差
```

例えば、ある特徴量は 0 から 1 の範囲、別の特徴量は 1000 から 10000 の範囲だと、値の大きい特徴量の影響が強く見えてしまうことがある。

オートスケーリングを行うと、特徴量ごとの単位やスケールの違いをそろえられる。

特に Lasso回帰やPLS回帰では、特徴量のスケールが結果に影響しやすいため、オートスケーリングが重要になる。

### 過学習

過学習とは、学習データに合わせすぎてしまい、未知のデータに対する予測性能が悪くなる状態。

典型的には、学習データでは誤差が小さいのに、テストデータでは誤差が大きい。

原因の例は次の通り。

- モデルが複雑すぎる。
- 特徴量が多すぎる。
- データ数が少ない。
- ノイズまで学習してしまっている。

対策としては、正則化、特徴量選択、次元圧縮、交差検証、データ数の増加などがある。

### 次元圧縮

次元圧縮とは、多数の特徴量をより少ない数の変数や成分に変換すること。

例えば、100個の特徴量を5個の成分にまとめるような処理。

次元圧縮の目的は次の通り。

- データを扱いやすくする。
- ノイズを減らす。
- 過学習を抑える。
- 特徴量同士の相関の問題を軽くする。
- 可視化しやすくする。

PLS回帰は、目的変数との関係を考慮しながら次元圧縮を行う回帰モデルと考えられる。

### 回帰

回帰とは、入力から連続値を予測する機械学習・統計モデルのタスク。

例:

- 面積や築年数から住宅価格を予測する。
- スペクトルデータから濃度を予測する。
- 材料の組成から物性値を予測する。

予測したい値が数値である点が重要。

### 線形

線形とは、特徴量に係数をかけて足し合わせる形で表されること。

```text
y = w1 x1 + w2 x2 + ... + b
```

線形モデルは解釈しやすい。係数 `w` を見ることで、どの特徴量が予測値を上げる方向に働くか、下げる方向に働くかを考えやすい。

ただし、特徴量と目的変数の関係が複雑な曲線的関係の場合、単純な線形モデルだけでは表現が足りないことがある。

### ハイパーパラメータ

ハイパーパラメータとは、モデルが学習によって自動的に決める値ではなく、人間が事前に設定する値。

例:

- Lasso回帰の `α`
- PLS回帰の `n_components`
- 決定木の深さ
- ニューラルネットワークの層数や学習率

一方、線形回帰の係数 `w` や切片 `b` は、学習によってデータから決まる値なので、通常はパラメータと呼ぶ。

ハイパーパラメータは、モデルの複雑さや正則化の強さを調整するため、予測性能や過学習に大きく影響する。

## 8. 口頭説明用の短いまとめ

最小二乗法は、実測値と予測値の差の2乗和を最小にするように係数を決める線形回帰で、シンプルで解釈しやすいが、外れ値や特徴量間の強い相関には弱い。

Lasso回帰は、最小二乗法にL1正則化を加えたモデルで、不要な特徴量の係数を 0 にしやすい。そのため、過学習を抑えながら特徴量選択もできる。

PLS回帰は、説明変数を目的変数と関係の強い少数の成分に変換してから回帰するモデルで、高次元データや特徴量同士の相関が強いデータに向いている。
