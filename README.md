# Python セミナー教材

研究室の後輩向け Python・機械学習セミナーの教材置き場（GitHub: fukumoto-riku/python_seminar）。

## 各回の内容

| 回 | 内容 |
|---|---|
| 第0回 | セミナー説明会（Pythonセミナー説明会.pptx） |
| 第1回 | Python セミナー資料（pptx） |
| 第2回 | Python 基礎演習・宿題ノートブック（lesson_2） |
| 第3回 | Lasso 回帰による MEDV 分析（lesson_3） |
| 第4回 | 特徴量エンジニアリング + Lasso / SVR（lesson_4） |
| 第5回 | kNN・ランダムフォレスト分類（lesson_5） |
| 第6回 | 可視化とクラスタリング（lesson_6） |
| 第7回 | 適用ドメイン（lesson_7、適用ドメイン.pptx） |

## 使い方

- 各回の `lesson_N/` は uv プロジェクト。`uv sync` で環境を作り、ノートブック（.ipynb）を実行する。
- 外部教材（`Pandas_100_knocks-master/`、`化学のためのPythonによるデータ解析・機械学習入門/`）は参照用で改変しない。
- セミナーの運営ルールは `メモ.md`、Git / GitHub の使い方は `Git_GitHub管理ガイド.md` を参照。
