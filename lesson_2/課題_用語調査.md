# 第2回課題: 結果と用語の意味

## 課題で出てきた結果が示していること

今回の課題では、分子データから `homo` という値を予測する回帰モデルを作成している。モデルには XGBoost が使われている。

実行結果では、次のように表示された。

```text
目的変数:homo,説明変数:217,データ数:10000
```

これは、予測したい値が `homo` であり、その予測に使う入力データが 217 個、全データ数が 10000 件あることを示している。

通常の XGBoost モデルでは、以下の評価結果だった。

```text
Training Set
Samples: 8000 | RMSE: 0.0987 | MAE: 0.0734 | R²: 0.9801

Test Set
Samples: 2000 | RMSE: 0.2602 | MAE: 0.1905 | R²: 0.8562
```

Training Set はモデルの学習に使ったデータ、Test Set は学習には使っていない確認用データである。Training Set の R² が 0.9801 と非常に高く、RMSE や MAE も小さいため、学習データに対してはかなり正確に予測できている。一方、Test Set では R² が 0.8562 で、学習データよりは性能が下がっている。これは、未知データに対する予測は学習データほど完全ではないが、かなりよく予測できていることを示す。

早期停止を使った XGBoost モデルでは、以下の評価結果だった。

```text
Training Set
Samples: 8000 | RMSE: 0.1267 | MAE: 0.0662 | R²: 0.9673

Test Set
Samples: 2000 | RMSE: 0.2510 | MAE: 0.1830 | R²: 0.8661
```

早期停止を使うと、Training Set の R² は少し下がったが、Test Set の R² は 0.8562 から 0.8661 に上がり、RMSE と MAE も少し小さくなった。つまり、学習データへの当てはまりを少し抑えることで、未知データへの予測性能が少し改善したと考えられる。

## 用語の意味

### 説明変数

説明変数とは、目的変数を予測するために使う入力データのことである。今回の課題では、`homo` 以外の分子記述子が説明変数になっている。

例えると、家賃を予測する場合の「部屋の広さ」「駅からの距離」「築年数」などが説明変数である。

### 目的変数

目的変数とは、予測したい値のことである。今回の課題では `homo` が目的変数である。

機械学習では、説明変数を `X`、目的変数を `y` と書くことが多い。

### 特徴量

特徴量とは、モデルに入力するデータの各項目のことである。多くの場合、説明変数とほぼ同じ意味で使われる。

今回の課題では、分子の性質を数値化した分子記述子が特徴量である。特徴量が 217 個あるということは、1 つの分子を 217 種類の数値情報で表しているという意味である。

### R2

R2 は決定係数とも呼ばれ、モデルが目的変数のばらつきをどれくらい説明できているかを表す指標である。1 に近いほど予測がよく、0 に近いほどあまり予測できていない。

今回の Test Set の R² が 0.8562 や 0.8661 であることは、未知データに対しても `homo` の変動をかなり説明できていることを示す。

### RMSE

RMSE は Root Mean Squared Error の略で、日本語では二乗平均平方根誤差という。予測値と実測値の差を二乗して平均し、その平方根を取った値である。

RMSE は誤差が大きいデータの影響を強く受ける。そのため、大きく外した予測があると RMSE は大きくなりやすい。値は小さいほどよい。

### MAE

MAE は Mean Absolute Error の略で、日本語では平均絶対誤差という。予測値と実測値の差の絶対値を平均した値である。

MAE は「平均してどのくらい外れているか」を直感的に表す。値は小さいほどよい。RMSE よりも外れ値の影響を受けにくい。

### 予測値-実測値プロット

予測値-実測値プロットとは、横軸に実測値、縦軸に予測値を取った散布図である。各点は 1 つのデータを表している。

グラフ上の点が対角線に近いほど、予測値が実測値に近いことを示す。点が対角線から大きく離れている場合、そのデータでは予測が大きく外れている。Training Set と Test Set のプロットを比べることで、学習データだけに強く当てはまっているのか、未知データにも同じように予測できているのかを確認できる。
